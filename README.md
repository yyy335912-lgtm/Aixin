# 浙江大学学生爱心社 · 志愿服务积分系统

> ZJU Club of Heart Caring · Service Hours & Points System
> 16 字宗旨：服务社会，奉献爱心，推己及人，薪火相传
> 长期目标：追求人类心中无差别的善

> 基于 Flask + SQLite 的全功能积分管理系统，替代原 WPS「智能表格」方案。
> 包含 8 大心暖系列品牌项目、8 个部门、学期任职、非常规活动等模块。

## 🏛️ 关于浙大爱心社

浙江大学学生爱心社（ZJU CHC = ZJU Club of Heart Caring）成立于 **1999 年**，由第一批受唐仲英基金会资助的学长学姐自发组织，是校内外具有重要影响力的公益类学生社团。

- **26 周年**（2024 年 12 月过 26 岁生日）
- 累计社员 **1000+** 人
- 长期目标：**追求人类心中无差别的善**
- 荣誉：
  - 2018 年起连续保持 **浙江大学五星级社团**
  - 八年荣膺 **浙江大学十佳学生社团**
  - 2022 年 **浙江省高校志愿公益类「活力社团」**
  - 2023 年 **榜样 100 全国大学生优秀社团排行榜 TOP100 教育类**
  - 2024 年 **浙江大学学生优秀社团**

**组织架构**：社长层（社长 + 团支书 + 秘书长 + 对内副社长 + 对外副社长）+ 社长助理 + 八大部门 + 六大心暖系列长期项目组，组成社团运营的**理事会**。

**与唐仲英基金会的渊源**：1998 年唐仲英先生在浙大设立唐氏基金，1999 年首批受助学生成立爱心社。基金会与社团日常联系密切：优秀志愿者评选、仲英青年学者结对、年度社长述职、「薪火 π」全国 22 校 24 社线下交流会、清华-CTF 领导力共创营等。

> 详细社团介绍、品牌活动、长期项目组文档见社团内部资料 `社团概况和部门介绍.docx`、`品牌活动及长期项目组介绍.docx`、`文字稿.docx`、`项目负责人工作内容及注意事项.docx`、`2025-2026年春夏学期工作规划.xlsx`。

- ⚙️ **可配置**：管理员密码、当前学期、部门列表均可在线配置

## 🧮 积分公式

```
总积分 = A类小时数 × 1.0 + B类小时数 × 0.5
```

- **A 类（公益服务类）**：陪伴老人、关爱自闭症儿童、支教、康复陪伴等面向受益人的服务，×1.0 计分
- **B 类（事务类）**：培训、年检、面试官、社团内部会议、物资整理等事务，×0.5 计分
- A/B 拆分到**参与者级别**：同一活动内不同人可有不同的 A/B 时长
- 活动本身有 A/B 总时长输入（仅作参考与汇总展示）
- 非常规活动（培训/面试官/年检等）支持 A/B 拆分录入

## 🚀 快速启动

### 1. 准备环境

需要 Python 3.8+。

```bash
# 安装依赖（一次即可）
pip3 install flask flask-sqlalchemy openpyxl
```

### 2. 初始化数据库

第一次运行需要先初始化数据库（自带示例数据）：

```bash
python3 init_db.py
```

会看到：

```
==================================================
✅ 数据库初始化完成！
   - 项目: 8 个
   - 社员: 61 人
   - 活动: 8 次
   ...
==================================================
🔑 管理员密码: aixin2026 (可在「系统设置」中修改)
==================================================
```

### 3. 启动服务

```bash
python3 app.py
```

打开浏览器访问：**http://127.0.0.1:5050**

默认管理员密码：`aixin2026`

> ⚠️ macOS 用户注意：系统偏好设置中**「AirPlay 接收器」**默认占用 5000 端口，本系统已使用 5050 端口避开该冲突。

## 📖 使用指南

### 社员视角

1. 打开首页，点击 **「查询我的积分」**
2. 输入**学号**和**姓名**（用于审计）
3. 查看个人积分与服务时长明细（A/B 时长分列显示）
4. 点击 **「我已确认，签收」** 完成签收

### 管理员视角

1. 首页点击 **「管理员入口」**，输入密码登录
2. 后台可以：
   - **社员管理**：添加 / 编辑 / 删除社员
   - **项目管理**：维护 8 大品牌项目及其积分规则
   - **活动管理**：登记新活动，每位参与者可分别填写 A/B 小时数
   - **任职积分**：每学期批量录入干部积分（支持手动 + 文件导入）
   - **非常规活动**：如唐奖、年检等零散活动，每位参与者可分别填写 A/B 小时数
   - **黑名单**：管理违规志愿者
   - **数据统计**：查看龙虎榜 / 部门积分（来自任职）/ 项目时长
   - **审计日志**：查看所有查询、签收、修改记录
   - **导出 Excel**：下载与原智能表格结构一致的多 Sheet Excel
   - **系统设置**：修改管理员密码、当前学期、部门列表

## 🌐 部署建议

## 🔧 进阶

### 修改部门列表

进入「系统设置 → 部门列表」直接修改，英文逗号分隔。

### 修改积分规则

进入「项目管理」，对每个项目设置「每小时积分」，默认 1.0。

### 重置数据库

```bash
python3 init_db.py
```

> ⚠️ 这会清空所有数据，仅用于初始化或重置。
